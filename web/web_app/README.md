# Правовой помощник (веб-версия)

Локальный справочник законов для государственных структур. Сайт запускается на компьютере (intranet) и открывается в браузере. Доступ — по ключам с датой окончания.

## Структура

```
web_app/
├── server/          # FastAPI-бэкенд
│   ├── app/
│   │   ├── main.py  # API (лицензии + кодексы)
│   │   ├── db.py    # БД SQLite: таблица ключей
│   │   └── codecs.py# загрузка кодексов из папки
│   └── run.py       # запуск сервера (порт 8080)
├── codecs/          # файлы кодексов (JSON)
│   ├── koap.json    # КоАП
│   └── uk.json      # УК РФ
├── client/          # React-фронтенд
└── start.bat        # запуск одной кнопкой
```

## Запуск

1. Установить зависимости (один раз):
   ```
   pip install -r server\requirements.txt
   ```
2. Запустить: `start.bat` → откроется `http://localhost:8080`

## Как добавить кодекс

Положить файл `*.json` в папку `codecs/` (формат — см. `koap.json`):
- `id` — уникальный ключ кодекса
- `name`, `short_name`, `category`, `color`
- `articles[]`: `number`, `title`, `text`, `type` (административная/уголовная/прочее), `fine` (штраф ₽), `stars` (1–5), `note`

## Управление ключами

1. Войти любым действующим ключом.
2. В боковом меню — «🔑 Управление ключами».
3. Генерация ключей (кол-во, срок действия, метка), добавление вручную, отзыв.
4. Админ-доступ по мастер-ключу — в заголовке запроса `X-Master-Key`. По умолчанию: `ADMIN-MASTER-2026` (изменить через переменную окружения `MASTER_KEY`).

## Пересборка фронтенда

```
cd client
npm install
npm run build
```

## Защита

- Без валидного ключа приложение полностью закрыто (только экран ввода).
- Ключ хранится в localStorage браузера.
- Ключи с датой окончания — после истечения доступ блокируется.
- Отзыв ключа мгновенно закрывает доступ.
